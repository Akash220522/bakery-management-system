# 🍰 Bakery Management System

A simple **Bakery Management and Billing System** built using **HTML, CSS, and JavaScript**.

This project allows users to add bakery items, generate a bill, perform CRUD operations, and download the bill.

---

## 🚀 Features

- Add bakery items
- Edit item details
- Delete items
- Generate bill
- Download bill
- CRUD operations
- Simple and responsive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage (for CRUD operations)
